# BCR Streamer — by BCR Studios

Free, ad-free, online-only music streaming. No subscriptions, no downloads at launch.

Live: https://bcr-streamer-api.onrender.com/

## Deploy on Render (Free, no paid services)
1. Render Dashboard → New → Static Site
2. Connect repo `makumejohn/bcr-streamer`
3. Build: no build needed (static)
4. Publish directory: `/`
5. Deploy — site goes live at https://bcr-streamer-api.onrender.com/

## Local
`python -m http.server 8000` and open http://localhost:8000
